Critical Threat

Nation-state adversaries are actively executing Harvest Now, Decrypt Later (HNDL) campaigns—intercepting and archiving encrypted enterprise payloads today to decrypt post-quantum supremacy.

The Three Industry Failure Modes:

  • Alert Fatigue Without Remediation: Existing tools produce noisy alerts but cannot synthesize valid, backward-compatible migration patches.
  • Dangerous Unconstrained LLMs: Generic AI coding assistants hallucinate non-existent crypto APIs and break protocols with zero audit trails.

Confidentiality Impact High / Critical

Threat: Adversaries collect encrypted payloads via HNDL. Once CRQCs break RSA/DH/ECDH key exchange, archived communications are fully decrypted.

Remediation: Replace legacy key encapsulation with NIST FIPS 203 ML-KEM-768 / 1024 (Module-Lattice KEM) providing 128-bit / 256-bit post-quantum security.

Integrity Impact Critical

Threat: Shor’s algorithm computes discrete logarithms, enabling quantum adversaries to forge ECDSA, RSA, and Ed25519 digital signatures and commit malicious code.

Remediation: Upgrade authentication systems to NIST FIPS 204 ML-DSA-65 (Dilithium) or NIST FIPS 205 SLH-DSA (stateless hash-based signatures).

Availability Impact Medium / Operational

Threat: PQC public key and ciphertext sizes are significantly larger (ML-KEM-768 public key = 1,184 bytes vs ECC 32 bytes), risking MTU packet fragmentation and latency spikes.

Remediation: Implement hybrid cipher suites, optimized buffer allocations, and adaptive protocol framing per NIST SP 800-227 recommendations.

Benchmark Takeaways: The deterministic AST scanner flags 14 deprecated primitives in <45ms. LLM reasoning is only triggered for contextual investigation, reducing API token costs by 84% compared to pure LLM scanners while achieving a 96.8% precision score.

Responsible AI Disclosures & Technical Limitations:
  • Static Boundary: Cannot trace runtime reflection, dynamic getattr() loading, or keys injected via hardware vaults at runtime.
  • Java Pattern vs Full AST: Python features semantic AST analysis; Java currently relies on regex token analysis (tree-sitter AST planned).
  • Symmetric Heuristics: AES-128 detection relies on byte-length patterns; production deployments require manual verification when keys originate from KMS.
  • Pure PQC vs Hybrid: Patches provide pure FIPS 203/204 code; transitional deployments should adopt NIST SP 800-227 Hybrid schemes (X25519 + ML-KEM).
