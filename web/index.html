Responsible Design — Disclosures & Limitations

  • Static Analysis Only: Performs AST node matching and regex catalog searches. Cannot trace dynamic code reflection or runtime dependency injection.
  • Context Blindness: Scanner cannot differentiate test mocks or sample fixtures from production microservices.
  • Hybrid Transition NIST SP 800-227: Recommends pure PQC (ML-KEM-768). Production environments should consider hybrid schemes (X25519 + ML-KEM-768) during migration.
  • Library Availability: Patches rely on liboqs-python or Bouncy Castle PQC, which must be installed in target environments.
  • Deterministic Human Authority: No code patch is ever applied automatically without explicit HITL human signature.
