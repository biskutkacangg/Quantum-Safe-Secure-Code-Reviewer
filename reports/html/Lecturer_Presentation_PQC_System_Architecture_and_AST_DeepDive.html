What is a Compiler? (The Official Code Translator)

The CPU is an electronic processor that only understands binary digits: 0 and 1 (Machine Code). It cannot comprehend human abstractions like if, def, class, or rsa.generate(). A compiler reads source code and systematically translates it into machine code so computers can execute it.

Hierarchical AST Tree vs. Flat Regex Scanner

Scientific Analysis: Why AST Outperforms Regex for Python & Why Regex is Optimal for Java JCA
Engine Comparison
Tree Traversal vs. Linear Stream
🌳 AST (Abstract Syntax Tree) — The Compiler Brain
  • Hierarchical Scope Awareness: Understands parent functions, classes, and nested variable definitions. It knows exactly which function an assignment belongs to.
  • Alias Resolution: Resolves from Crypto.PublicKey import RSA as my_rsa ➔ maps my_rsa directly to RSA.
  • Zero Comment False Positives: Ignores text inside comments. A comment like # TODO: replace RSA is never falsely flagged!
  • Deterministic 96.8% Precision: Validates real syntax trees without relying on text heuristics or blind LLM guesses.
🔍 Regex (Regular Expression) — The Flat Scanner
  • Flat Linear Stream: Scans raw character sequences left-to-right (Finite State Automaton / DFA / NFA).
  • No Concept of Hierarchy: Cannot tell whether a token is inside a class, a function, or a docstring comment.
  • Why Used for Java: Perfectly matches standard Java Cryptography Architecture (JCA) factory patterns (KeyPairGenerator.getInstance("RSA")) without needing a heavy JVM compilation step.
  • Low Runtime Overhead: Scans Java source files instantly (< 20ms).
